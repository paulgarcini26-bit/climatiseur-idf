# AMZ Climatisation

Une page professionnelle prête pour GitHub Pages.

## Mise en ligne

1. Envoyer `index.html` et le dossier `assets` dans un dépôt GitHub.
2. Aller dans `Settings > Pages`.
3. Choisir `Deploy from a branch`, branche `main`, dossier `/root`.
4. Enregistrer.

Le fichier `index.html` doit être directement à la racine du dépôt.
